### github的基础知识
- 组织：github的功能，允许用户将多个个人账户、项目和团队集合在一起，以共同管理和协作开发。
- 仓库：GitHub仓库是用于存储项目文件和版本历史的核心单元。每个仓库都可以看作是一个独立的代码库，其中包含了项目的所有文件、目录、提交历史以及相关的元数据。
- 分支：分支是从主线上分离出来进行另外的操作的代码线。分支的存在既不影响主线，主线又可以继续其原有的工作流程。
  主要作用：
  1. 并行开发：每个分支都是代码的独立副本，可以并行推进多个功能的开发。
  2. 版本管理：分支使得版本管理变得更为轻松。当一个分支的代码稳定后，可以将其合并到主分支进行发布，而不会影响其他正在进行的开发工作。
  3. 故障隔离：如果在开发中遇到问题或发生错误，可以创建一个新分支来排查和修复问题，而不会影响其他分支的代码。
   
   常见分支类型：
  1. 主分支（main）：稳定版本
  2. 开发分支（dev）：开发新功能或修复bug

### git操作
#### Git初始化
1. git init //将本地文件夹初始化为本地Git仓库，从而可以使用Git进行版本管理
2. git add . //将当前目录加入暂存区
3. git commit -m "first commit"// 初次提交
   
#### 修改并提交
1. 进行修改
2. git add <修改的文件相对路径>
3. git commit -m "<修改的内容>"

#### 分支与合并
1. git checkout -b <分支名>//创建分支
2. git checkout main //切换分支
3. git log --oneline //以简洁的方式打印commit日志
4. git diff main <分支名>//查看main/和指定分支的差异
5. git merge <分支名>//将<分支名>合并到当前所在分支
6. 若不想保留分支，使用git branch -d <分支名>

#### 回退
1. 
```bash
# 回退（丢掉当前分支的最后一次提交）
 git reset --hard HEAD~1
```
#### 本地Git仓库与远端仓库
1. 建立跟踪关系
```bash
git remote add origin `你的远程仓库地址`
git push -u origin main
```
2. 远程协作
```bash
# 拉取远端代码
git pull

# 推送本地代码到远端（commit之后）
git push
```

### 常用的git命令
|命令|作用|什么时候用|
|-----|-----|-----|
|git add <修改的文件>|增加修改到暂存器|提交修改前|
|git commit -m "修改注解"|提交修改到本地Git仓库|将本地修改推送到远端前|
|git push origin <分支名>|将本地当前分支的提交推送到远端对应分支|推送|
|git checkout -b <分支名>|创建并切换分支|需要创建个人dev和功能开发分支时使用|
|git diff <分支A> <分支B>|查看分支A、B的差异|与main比较时用于代码发布前核对；代码评审\自查；查看本地与远程进度|
|git log --oneline|以简洁的方式输出commit日志|用于回退前确认回退的版本|
